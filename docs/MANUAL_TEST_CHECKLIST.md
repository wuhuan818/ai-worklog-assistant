# 人工验收清单

- [ ] VS Code 启动插件并显示 Worklog Activity Bar。
- [ ] 开始任务后状态栏显示 Worklog，任务写入 SQLite。
- [ ] 保存文件产生 `file_saved` 事件。
- [ ] 创建 Bug、切换/解决 Bug、添加备注。
- [ ] 结束任务生成 Mock 草稿并打开审核 Webview。
- [ ] 编辑 JSON 内容并确认，生成 `knowledge/daily-records` 和项目任务 Markdown。
- [ ] 使用 `AI Worklog: Search Knowledge Base` 或 API 关键词搜索找到记录。
- [ ] 后端停止时插件只提示错误，不崩溃。
