# 60-second Demo Video Plan

目标时长 56–58 秒，最多 60 秒。录制前完成一次真实 Demo；视频通过页面切换回顾已完成状态，不等待网络生成。

| 时间 | 页面与鼠标操作 | 画面重点 | 旁白 / 字幕 |
|---|---|---|---|
| 0–4s | 标题卡或 VS Code 主窗口 | 项目名与侧边栏图标 | “AI Worklog Assistant：VS Code 内的工作记录与知识沉淀助手。” |
| 4–15s | `hello.js`、终端、AI Worklog 侧栏 | 报错、任务、Bug、修复后成功输出 | “从真实开发错误开始，任务、文件变化和 Bug 被显式记录。” |
| 15–28s | AI 总结审核页 | 结构化任务总结、代码变更、命令结果、Bug 解决方案 | “完成任务后，系统先构建受控 Context，再生成结构化总结。” |
| 28–37s | Revision / Approved 状态 | 保存 Revision、批准后的状态 | “AI 草稿可以人工修改；只有批准版本才进入正式输出。” |
| 37–45s | 导出或历史任务 | Markdown 导出与可回看的任务 | “批准内容可导出为 Markdown，形成可追溯的工作记录。” |
| 45–55s | Published Knowledge 搜索；可选 RAG 引用 | 搜索 `ReferenceError`，或回答与引用 | “有价值的候选经选择发布后，成为可检索、可引用的知识。” |
| 55–58s | 简洁收尾画面 | 侧栏或知识结果 | “把每次开发过程，自动沉淀成下一次可以复用的知识。” |

录制检查：关闭 Settings、Output、终端历史中无关命令和保存对话框；绝不展示 API Key、Authorization、Provider 原始响应、reasoning、数据库、Git 或本机用户目录。建议简短旁白加同文字幕；没有真实 RAG 成功时，用知识搜索结果结束即可。
